# 🏥 MediCure AI – Smart Healthcare & Appointment Platform

**Your Health. Your Time. Our Care.**

MediCure AI is a modern healthcare platform designed to simplify doctor discovery, appointment booking and patient management through an intuitive digital experience.

🌐 **Live Demo:** https://medicure-ai-ten.vercel.app

💻 **GitHub Repository:** https://github.com/keerthikamithili-svg/MEDICURE-AI

---

## 🚀 Project Overview

MediCure AI aims to make healthcare services more accessible and convenient by connecting patients with healthcare providers through a centralized platform.

The application focuses on simplifying appointment management, improving the patient experience and supporting efficient healthcare administration.

## ✨ Key Features

- **Patient Portal** – Patient login and account access.
- **Doctor Discovery** – Explore doctors and clinical specialties.
- **Appointment Booking** – Schedule healthcare appointments.
- **Appointment Management** – View and manage appointment records.
- **Appointment History** – Access previous appointment details.
- **Role-Based Access** – Separate interfaces for patients, doctors, front desk and administrators.
- **AI Integration** – Gemini API integration for AI-powered application capabilities.
- **Database Integration** – Supabase for application data management.

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/keerthikamithili-svg/MEDICURE-AI.git
```

### 2. Navigate to the project

```bash
cd MEDICURE-AI
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file in the project root and configure:

```env
GEMINI_API_KEY=your_gemini_api_key
APP_URL=http://localhost:3000

VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_publishable_key
```

Use your own API credentials. Never upload private keys or secrets to GitHub.

### 5. Run the application

```bash
npm run dev
```

### 6. Build for production

```bash
npm run build
```

## 🗄️ Database

MediCure AI uses Supabase as its database platform.

The repository includes SQL schema files in the `supabase/` directory.

Configure your Supabase project and run the provided schema in the Supabase SQL Editor before using database-dependent features.
